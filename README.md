# Utsav Bhattarai - Portfolio

A personal portfolio website built with Next.js to showcase my projects, skills, and background as a Full Stack developer and open-source contributor.

# Portfolio Structure

```bash
Home
├── Introduction
├── Featured Projects
├── Skills & Technologies
├── Newsletter Signup
└── Contact Information

About
├── Background
├── Experience
└── Gallery

Projects
└── List of Projects
```
